# TennisOS

Personal voice-first tennis coaching workspace.

## Deployment

Vercel hosts the app. Set `OPENAI_API_KEY` in Vercel environment variables; never commit it to Git.

## Features

Voice conversations, match tracking, training priorities, coaching hypotheses, and local-browser journal storage.

## Status

Source files will be synced from the existing Vercel deployment. Cloud database persistence is not yet implemented.
